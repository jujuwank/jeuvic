# JEUVIC V0.11.1

Plateforme multi-jeux JEUVIC avec BIBLEQUIZZ et RÉVÉLATION.

## RÉVÉLATION V1.0.4
- Banque Google Sheets officielle utilisée automatiquement lorsque le champ est vide.
- Intervalle standard de 3 secondes entre les indices.
- Audio `buzzer.mp3` au buzz accepté.
- Barre arbitre : LANCER, RÉPONSE, QUESTION SUIVANTE, SCORE.
- Panneau latéral : état, points, joueur ayant buzzé, PASSER et TERMINER LA PARTIE.
- Valeur de la question visible sur les interfaces arbitre, joueur et spectateur.

## Audio
Place les fichiers audio réels dans `games/revelation/assets/audios/` en conservant les noms :
- `fin.mp3`
- `buzzer.mp3`
- `reponse-fausse.mp3`
- `reponse-juste.mp3`
