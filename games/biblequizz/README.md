# BIBLEQUIZZ V1.5.0

Le jeu utilise Firebase/Firestore pour synchroniser l'arbitre, les joueurs et la projection. Les classements restent privés pendant la manche et sont publiés uniquement par l'arbitre à la fin de celle-ci.


- Le nombre de points de la question est visible chez le joueur et sur la projection.
