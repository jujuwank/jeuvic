# RÉVÉLATION V1.0.4

Deuxième jeu officiel de JEUVIC.

- Indices progressifs toutes les 3 secondes par défaut
- Buzzer atomique Firestore
- Interfaces arbitre, joueur et projection
- Classement synchronisé
- Banque Google Sheets officielle par défaut
- Valeur de la question visible sur les trois interfaces
