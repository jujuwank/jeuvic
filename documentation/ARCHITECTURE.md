# Architecture JEUVIC

Cette version pose la base du projet.

## Principes

- Préfixe CSS : `jv-`
- Objet global JavaScript : `JEUVIC`
- CSS séparé par responsabilité
- JavaScript séparé par module
- Données configurables dans `config.js` et `constants.js`

## Prochaine étape

Développer le moteur de partie : joueurs, statuts, salle d'attente, scores.
